The first release of CursorDrop: drop a cursor pack into a folder and it becomes your Windows cursors.

**Download `CursorDrop-v1.0.0-win64.zip`**, unzip it anywhere and run `CursorDrop.exe`. Portable, no installer, no admin rights. Windows 10 / 11, 64-bit.

### What it does
- Watches its `cursors` folder: `.zip`, `.7z` and `.rar` packs are applied within a couple of seconds, straight from the archive. Archives inside archives ("all-in-one" packs) are opened too.
- Works out each cursor from the pack's install `.inf`, or from file names when there isn't one. Missing cursors fall back to the Windows default.
- A window with your packs in an Explorer-style list (sortable, resizable columns) and, for each pack, a grid of all 17 cursors: what you have now next to what you'd get, with animated cursors playing.
- Packs with several variants get browser-style tabs named after their folders, scrollable with arrows, the mouse wheel or the arrow keys.
- Remembers your cursors before applying a pack: **Restore original cursors**, or just delete the pack.
- Add packs with **Add pack…** or by dragging them onto the window; remove them to the Recycle Bin.
- Lives in the tray, optional Start with Windows, follows Windows' light/dark mode and accent colour (or pick Light / Dark), always-on-top pin.
- Command line: `--inspect <pack>` to preview a pack's mapping, `--restore`, `--tray`, `--version`.

Only your own user's cursor settings are changed (`HKEY_CURRENT_USER`).

SHA-256 of the zip is in `CursorDrop-v1.0.0-win64.zip.sha256`.
